# Global Seismic Monitoring Dashboard

Interactive earthquake monitoring dashboard built using earthquake datasets and Google Data Studio to visualize global seismic activity trends, earthquake distribution, magnitude patterns, and depth analysis in 2026.

---

## Project Overview

This project aims to provide an interactive seismic monitoring dashboard for analyzing global earthquake activity. The dashboard helps users explore earthquake occurrences based on magnitude, depth, location, and time distribution.
The project combines data visualization and geoscience analysis to support earthquake monitoring and exploratory seismic analysis.

---

## Features

- Global earthquake monitoring map
- Earthquake trends over time
- Magnitude distribution analysis
- Earthquake depth analysis
- Country and magnitude filtering
- Top earthquake events table
- Interactive dashboard visualization

## Key Insights

- Most earthquake events occurred in regions located around the Pacific Ring of Fire.
- Earthquake activity showed fluctuating patterns throughout 2026.
- Several high-magnitude earthquakes were identified in Indonesia, the Philiphines, Japan, Tonga, and Vanuatu.
- Deep-focus earthquakes tend to occur in subduction zone regions.
